RAKSHA BANDHAN WEBSITE

1. Open index.html in a browser.
2. Put your photos in:
   assets/images/memory1.jpg
   assets/images/memory2.jpg
   assets/images/three-person-sketch.jpg
3. Put your Telugu song in:
   assets/audio/final-telugu-song.mp3
4. Open admin.html to edit the local demo settings.

IMPORTANT:
The included admin page is a local prototype, not a secure public authentication system.
For a publicly hosted website with secure admin login, persistent uploads and database storage, connect this frontend to a backend such as Supabase/Firebase or another secure server.
